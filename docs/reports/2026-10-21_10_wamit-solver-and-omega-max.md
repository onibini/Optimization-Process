# 업데이트 보고서: WAMIT 반복 솔버와 주파수 상한 설정

- 날짜: 2026-10-21
- 범위: `src/physics/wamit_handler.py`, `src/physics/power_calc.py`, `src/problems/*`, `main.py`, `config.cfg`, `tests/test_wamit_options.py`(신규), `README.md`, `docs/`

## 1. 배경

5기 평가 한 번이 8초 이상 걸려 최적화 반복이 느렸습니다. 매뉴얼(14.2절)에 따르면 `ISOLVE=1`(직접 솔버)은 시간이 NEQN³에 비례하고 NEQN² 크기의 복소 배열이 메모리에 필요하며, `ISOLVE=0`(반복 솔버)은 NEQN² × 반복 횟수에 비례하고 그 임시 저장이 필요 없습니다.

## 2. 변경 내용

- `config.cfg`의 `[WAMIT Settings]`에 `Solver`(기본 0, 반복 솔버)와 `OmegaMax`(기본 3.0 rad/s)를 추가했습니다. `Solver`는 `wec.cfg`의 `ISOLVE`로, `OmegaMax`는 `wec.pot`의 `NPER`로 반영됩니다(주파수는 0.5 rad/s부터 0.05 간격, 점 수는 `OmegaMax`에서 계산, 최소 3점). 값이 잘못되면 시작할 때 오류로 종료합니다. 두 설정 모두 이전과 같은 값이면 격자·결과가 동일하며, 기본 솔버만 직접(1)에서 반복(0)으로 바뀌었습니다.
- `MAXITT=100`은 그대로입니다. 반복 솔버가 `MAXITT`에 도달해 수렴하지 못해도 WAMIT은 경고만 하고 진행하므로, `run_wamit`이 `wec.out`의 주파수별 반복 횟수 표(`find_unconverged`)를 읽어 해당 주파수를 경고합니다.
- `calculate_power`가 주파수 격자의 마지막 점에서 발전 밀도가 최대값의 5%를 넘으면 `OmegaMax`가 응답을 잘랐을 수 있다고 경고합니다.

## 3. 측정 결과 (5기, 수직벽 켬, 이 PC의 32-bit WAMIT)

- 솔버: 기당 1/4 패널 81개(전체 405개)에서 직접 8.1초 → 반복 5.6초(1.45배), 전체 1,025개에서 103초 → 37.7초(약 2.7배), 전체 1,320개(NCPU=4)에서 287초 → 84초(약 3.4배). 파워는 같습니다(17,939.58 W와 17,939.59 W). 주파수별 반복 횟수는 9~22회로 `MAXITT` 안에서 수렴했습니다.
- `OmegaMax`(Solver=0, 기당 패널 80, 시간은 3.0/2.45/2.0 순. 측정 당시 기본 메쉬 조건이며, 80패널은 이후 일부 형상에 부족한 것으로 확인되어
  기본값이 120으로 바뀌었습니다. 아래 파워 변화는 같은 메쉬끼리의 상대 비교라 결론은 유지되지만 절대 시간은 120패널에서 약 2배입니다):

| 사이트·형상 | 파워 변화 (2.45 / 2.0) | 시간 |
| --- | --- | --- |
| 영일만 R=2.5, D=5.0 | 0% / 0% | 5.6 / 4.3 / 3.3초 |
| 영일만 R=1.5, D=2.5 | 0% / -0.08% | 5.2 / 4.2 / 3.3초 |
| 영일만 R=0.5, D=2.0 | -0.03% / -13.7% | 5.9 / 5.3 / 3.5초 |
| 영일만 R=0.5, D=0.5 | **-24.4% / -55.4%** | 5.6 / 4.4 / 3.4초 |
| 칠발도 R=0.5, D=0.5 | **-40.6% / -72.0%** | 7.0 / 4.5 / 3.4초 |

  큰 WEC은 상한을 낮춰도 같지만 작고 얕은 WEC은 고주파에서 공진하므로, 탐색 범위(R 0.5~2.5, D 0.5~5.0)에 작은 WEC이 있는 기본 설정에서는 3.0을 유지해야 합니다. 그래서 기본값은 3.0이고, 고정 형상(OptMode 2)이나 범위가 큰 WEC에서만 줄이는 것을 권합니다.
- 주파수 격자: 균일 0.05 간격 51점은 영일만 R=2.5, D=5.0에서 파워를 약 +4%(17,940 W 대 101점 17,279 W, 201점 17,229 W) 과대평가했습니다. 좁은 공진(ω≈1.13, RAO 7~11) 때문이며, 공진 부근만 촘촘하게 한 비균일 49점은 201점 결과와 0.02% 차이였습니다. 이번에는 격자를 바꾸지 않았고(공진 주파수가 설계마다 달라 설계별 격자가 필요), 후속 작업으로 남깁니다.
- NCPU: 반복 솔버에서 1/2/4/8/10/17 CPU가 25.0/13.4/7.3/5.4/4.9/4.6초이고, 필요한 RAM이 NCPU에 비례해 NCPU=8에서 전체 1,320 패널이 메모리 오류, NCPU=4에서는 성공했습니다. 평가 여러 개를 동시에 돌려도 처리량은 늘지 않았습니다(이 PC에서 평가당 약 5~6초로 동일).
