# 업데이트 보고서: CMA-ES 설정 시험과 3개 해역 동시최적화 제출 (`run_sites.py`)

- 날짜: 2026-10-23
- 범위: `scripts/experiments/run_sites.py`(신규), `tests/test_run_sites.py`(신규). `src/` 변경 없음.

## 1. 개요

CMA-ES의 성능을 다시 평가하기 위해 부안·칠발도·영일만항 동시최적화(5 WEC)를 계산용 PC에서 실행한다. 사용자의 요청에 따라 일반적인 설정을 정하되, 필요하면 하이퍼파라미터를 먼저 조정했다. 조정은 WAMIT 없이 실제와 같은 탐색 공간에서 가짜 목적함수로 했다.

## 2. 변경 내용

- **설정 시험(이 PC, WAMIT 없음):** 실제 7차원 탐색 공간(0.1 격자, 최소 간격 4, 대칭 정렬, 패널티)에 회전·비등방 이차함수(최적점 = 논문 부안 동시최적해)를 얹고, 배치 변수에 코사인 굴곡을 더한 두 함수(rugged: 진폭 0.02·6주기, rugged2: 0.05·10주기)로 프로젝트의 `run_cma_es`와 `run_de`를 비교했다. 평가 5,400회, 설정마다 8회 반복.

| 설정 | 매끄러움: 중앙값 차이 / 정확히 찾음 | rugged | rugged2 |
| --- | --- | --- | --- |
| CMA-ES λ=9 (표준 4+⌊3 ln 7⌋), σ0=0.2/0.3/0.5 | 0.04~0.07% / 3~4회 | 3.9~7.2% / 0~1회 | - |
| CMA-ES λ=18 | 0% / 7~8회 | 0~1.9% / 3~5회 | - |
| CMA-ES λ=36, σ0=0.3 | 0% / 8회 | 0% / 6회 | 0.9% / 3회 |
| CMA-ES λ=54, σ0=0.3 | - | 0% / 8회 | 0.5% / 4회 |
| **CMA-ES λ=72, σ0=0.3** | - | **0% / 8회** | **0% / 5회 (최악 0.74%)** |
| DE (개체 100, F 0.5, CR 0.9) | 0% / 8회 | 0% / 8회 | 0% / 7회 (최악 0.11%) |

  결론: 표준 개체 수(9)는 굴곡이 있는 문제에서 국소해에 갇힌다(예전에 CMA-ES가 부정확했던 원인일 가능성). 개체 수를 72로 키우면 안정적이다. σ0의 영향은 개체 수보다 작아 표준값 0.3을 쓴다. 학습률 등 나머지 내부 상수는 표준식 그대로다. 같은 평가 수에서 튜닝한 CMA-ES도 DE보다 약간 약했다(가짜 함수 결과).
- **실행 설정:** `OptMode=3`, `NumWECs=5`, `Algorithm=4`, `PopSize=72`, `MaxIter=300`, `SigmaInit=0.3`, `WaveSpec=1`(ITTC; 논문 수치와 일치한 스펙트럼), `MeshPanels=120`, `FreqGrid=0`(균일 0.05, 51점), `MinSpacing=4`. 조기 종료 없음. 난수 시드 고정 없음(해역당 1회).
- **`scripts/experiments/run_sites.py`:** 하나의 작업 안에서 여러 해역을 순서대로 `main.main`으로 실행한다(설정의 `SiteID`만 바꾼 `config_site<N>.cfg`를 만들어 사용). 한 해역이 실패해도 다음 해역을 실행하고, 실패가 있으면 종료 코드 1.
- **제출:** 작업 `20261023_161543_cmaes_sites`(2026-10-23 16:15 시작). 해역당 최대 21,600회 평가(캐시 제외), 예상 1.5~3일.
