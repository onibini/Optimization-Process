# 업데이트 보고서: 사용 설명서를 일반 사용자용으로 다시 쓰기

- 날짜: 2026-10-23
- 범위: `docs/manual_ko.md`(재작성), `README.md`(문구 3곳)

## 1. 개요

이 프로그램은 다른 사람도 쓰도록 배포하는 것이 목적이다(사용자). 앞 버전(`2026-10-23_19`)의 설명서에는 작성자에게만 해당하는 내용(계산용 PC로 보내는 원격 실행을 기본 흐름처럼 설명, 논문과 프로그램의 WEC 번호 차이, 작성자의 이전 결과와 비교하는 설정, 기본 스펙트럼 변경 이력)이 섞여 있었다. 이를 빼고 누구나 쓸 수 있는 설명서로 다시 썼다.

## 2. 변경 내용

- **설명서(docs/manual_ko.md)**
  - 뺀 것: 원격 실행 절차(부가 도구 표의 선택 항목으로만 남기고 설정 문서 링크), 논문 번호 대응 안내, "논문과 비교하려면" 설정, 스펙트럼 기본값 변경 이력, 작성자 작업 ID·경로가 들어간 명령.
  - 더한 것: 계산 과정 설명(1-2), 설계 변수와 WEC 번호 규칙을 프로그램 자체의 규칙으로 설명(1-3, 1·3·5기), 알고리즘 표, 설치 절차(git clone, 경로에 공백이 있을 때 `setx WAMIT_EXE`), 처음 실행할 때 작게 돌려 시간 재기, `Workers`가 효과를 내는 경우, 해역 데이터 열 설명과 새 해역 추가법, 범용 팁(시간 어림, 범위 설정), 다른 형상·개수를 쓰는 방법(FAQ).
  - 명령은 Windows cmd 기준이며, WAMIT이 필요 없는 작업은 다른 OS에서도 같은 명령으로 된다고 밝혔다.
- **README**: "compute PC" 표현을 "선택 사항인 SSH 원격 실행"으로 바꿨다(주요 기능 표, 폴더 구조, 문서 링크).

## 3. 호환성 영향

없음(문서만).

## 4. 검증

- 설명서의 설정 키·기본값·경고 문구·명령(`run_sites.py --sites ... --config ...`, `main.main(cfg)`)을 현재 코드와 대조했다.
- README와 설명서에 "계산용", "compute PC" 같은 작성자 전용 표현이 남지 않은 것을 검색으로 확인했다.
- 단위 테스트, `ruff check .`, `ruff format --check .` 통과(코드 변경 없음).

## 5. 남은 이슈 / 후속 작업

- 영문 설명서는 아직 없다(해외 사용자를 고려하면 추가 권장).
- `docs/remote_compute.md`, `docs/validation/`은 작성자의 환경·결과 기록이라 그대로 두었다(README에서는 선택 사항으로만 링크).
