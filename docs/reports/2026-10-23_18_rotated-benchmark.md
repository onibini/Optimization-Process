# 업데이트 보고서: 변수끼리 얽힌(회전) 벤치마크로 최적화 알고리즘 다시 비교

- 날짜: 2026-10-23
- 범위: `scripts/experiments/algorithm_benchmark.py`(`--rotate`), `tests/test_algorithm_benchmark.py`

## 1. 개요

앞의 비교(`2026-10-23_11`)에서는 함수 몇 개가 변수끼리 독립(분리 가능)이라 변수를 하나씩 바꾸는 GA에 유리했다. WEC 문제는 형상과 배치 변수가 서로 얽혀 있으므로, 함수를 고정된 회전 행렬로 돌려 변수끼리 얽히게 한 뒤 다시 비교했다. 격자는 WEC 문제와 같은 변수별 칸 수(R 20, D 45, x 220, y 299)다.

## 2. 변경 내용

- `--rotate`: 함수를 `f(Q (x − x*) + x*)`로 계산한다. Q는 차원마다 고정된 무작위 직교 행렬, x*는 최소점이다(최소값은 그대로).
- 실행: DE, PSO, DEPSO, CMA-ES(λ=72), GA × 함수 6개 × D 7·20, 평가 20,000회, 20회 반복(20 프로세스, 16분).

## 3. 호환성 영향

없음(시험 스크립트 옵션).

## 4. 검증 (결과)

**평균 순위** (회전 Schwefel 제외 10개 경우, 1이 가장 좋음): **CMA-ES 2.4**, PSO 2.5, DE 2.6, DEPSO 3.0, GA 4.5.

- **GA**는 변수끼리 얽히면 크게 나빠졌다(분리 가능 함수에서의 강점이 사라짐).
- **CMA-ES**는 고차원·다봉 함수(Rastrigin, Rosenbrock D20, Ackley D20)에서 가장 좋았다. 공분산이 변수 사이의 얽힘을 학습하기 때문이다.
- **DE**는 7차원 문제(WEC 문제와 같은 차원)에서 Ackley, Griewank, Rosenbrock, Sphere가 가장 좋거나 동률이었다.
- **DEPSO**는 DE보다 나쁜 경우가 없고 4개에서 좋았다.
- **주의**: 회전한 Schwefel은 점이 원래 범위(±500) 밖으로 나가면 값이 음수가 될 수 있다. 그래서 진짜 최소값이 바뀌어 비교에서 뺐다.
- 단위 테스트(회전 행렬 직교성·변수 결합·결과 차이), `ruff check .`, `ruff format --check .`, 전체 테스트 통과.

## 5. 남은 이슈 / 후속 작업

- 벤치마크 결과로는 7차원에서 DE와 CMA-ES가 비슷하고 고차원에서는 CMA-ES가 낫다. 실제 WEC 문제의 비교는 계산용 PC의 CMA-ES 작업(`20261023_190757_cmaes_sites2`) 결과와 논문 DE 최적해로 판단한다.
- 회전 Schwefel처럼 범위 밖에서 정의가 깨지는 함수는 다음 비교에서 빼거나 범위를 바꿔야 한다.
