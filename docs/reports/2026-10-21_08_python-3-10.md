# 업데이트 보고서: 최소 Python 버전을 3.10으로 상향

- 날짜: 2026-10-21
- 범위: `ruff.toml`, `.github/workflows/python-tests.yml`, `.github/pull_request_template.md`, `README.md`, `CLAUDE.md`, `CONTRIBUTING.md`, `docs/architecture.md`, `src/physics/mesh_axisymmetric_shape.py`, `src/utils/validation.py`, `tests/`

## 1. 배경

Python 3.8은 지원이 종료되었고(2024-10), 최신 numpy/scipy는 3.8에서 설치되지 않아 CI 3.8 항목이 실패할 가능성이 컸습니다. 개발 환경은 Python 3.11(conda `py311`)입니다. 최소 지원 버전을 3.10으로 올렸습니다.

## 2. 변경 내용

- `ruff.toml`: `target-version`을 `py38` → `py310`으로 변경.
- CI 테스트 매트릭스를 `3.8, 3.12` → `3.10, 3.12`로 변경 (lint 잡은 3.12 유지).
- README(Prerequisites, CI 설명), `CLAUDE.md`, `CONTRIBUTING.md`, PR 템플릿, `docs/architecture.md`의 버전 표기를 3.10으로 맞춤.
- `mesh_axisymmetric_shape.py`: 3.8용 `from __future__ import annotations`와 주석 제거 (3.10에서는 불필요).
- target이 올라가며 ruff `B905`가 활성화되어 `zip(...)`에 `strict=True`를 명시 (`validation.py` 2곳, 테스트 3곳). 길이가 다른 입력은 조용히 잘리는 대신 `ValueError`가 됩니다.

## 3. 검증

py311에서 `ruff check .`, `ruff format --check .`, 단위 테스트 59건(skip 3) 통과. 3.10과 3.12는 이 PC에서 실행하지 않았으므로 첫 CI 실행에서 확인이 필요합니다.
