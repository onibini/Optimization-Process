# 업데이트 보고서: 주파수 격자 시험 도구 2차 개정 (구간 상단 1.1, 0.003125 확인 격자, B_pto 포물선 보간)

- 날짜: 2026-10-22
- 범위: `scripts/experiments/freq_grid_study.py`, `tests/test_freq_grid_study.py`, `docs/frequency_grid_design.md`, `CHANGELOG.md`, `report/`

## 1. 개요

2차 시험(`2026-10-22_08` 보고서)에서 (1) 현재 격자 오차의 주원인이 `B_pto`가 격자 점에 걸려 달라지는 것이고, (2) 좁은 공진 형상(R=0.5, D=2.0)은 어떤 격자도 통과하지 못했으며, (3) 구간 상단(`1.0·ω0`) 바로 위에서 공진의 오른쪽 날개가 손실된다는 것을 확인했습니다. 제안 1, 2와 `B_pto` 보간의 시험 도구 내 재현을 승인받아 반영했습니다. `src/` 물리 코드는 바뀌지 않았고 계산용 PC에는 제출하지 않았습니다.

## 2. 변경 내용

- **후보 추가:** 적응형 `0.85~1.1`(미세 0.0125, 꼬리 0.1)와 `0.85~1.1`+미세 0.00625.
- **0.003125 확인 격자:** R=0.5, D=2.0에만 `check_uniform_0.003125`(801점)를 기준격자 바로 뒤에 추가. 기준 판정에서는 제외하고, 모든 후보의 오차를 이 격자 대비로도 기록(`*_vs_check_*` 열)해 0.00625 기준 자체의 수렴을 확인합니다.
- **`B_pto` 포물선 보간(시험 도구 내부, `src/` 변경 없음):** `rao_calc.calculate_rao_matrix`와 같은 계산을 `rao_with_bpto`로 다시 구현했습니다. `node`는 현재 동작(비제어 RAO 최대 격자점의 방사 감쇠), `interp`는 최대점과 양 옆 두 점을 지나는 포물선의 꼭짓점 주파수에서 같은 세 점의 `B_kk`를 2차로 보간한 값을 `B_pto`로 씁니다(격자 끝점이거나 포물선이 위로 볼록하지 않으면 `node`로 대체). 같은 WAMIT 실행에서 두 방식을 모두 계산하므로 추가 WAMIT 시간은 없습니다.
- **판정:** 후보마다 `node`/`interp` 두 행을 만들고 각각 자기 방식의 기준격자와 자기 방식의 균일 격자(시간 기준)로 판정합니다. 요약 표에서 `+interp`가 붙은 행이 보간 방식입니다. 새 열: `total_W_interp`, `err_total_interp_pct`, `worst_wec_err_interp_pct`, `peak_interp_*`, `bpto_node`/`bpto_interp`(5기 값), `reimpl_check`(재구현이 원래 결과와 같은지; 정상이면 1e-15 수준).
- 시험 중 `rao_with_bpto("node")`가 원래 `calculate_rao_matrix`와 어긋나면 `reimpl_check`로 바로 드러납니다.

## 3. 호환성 영향

- `src/`, `config.cfg`, `main.py`, WAMIT 입력은 그대로입니다.
- `freq_grid_study_grids.csv`와 `..._verdict.csv`의 열이 늘었고, 판정 CSV에 `method` 열이 추가되었으며 행 수가 2배가 됩니다(`node`, `interp`).
- `grids --quick`의 계산량이 늘어납니다: 후보 2개와 확인 격자 801점이 추가되어 점 수 합계가 약 7,000이 되고, 점당 약 0.13초 기준으로 약 15~17분으로 예상합니다(2차 시험 11.4분).

## 4. 검증

- 이 PC에서 WAMIT 없이 확인했습니다. 새 테스트 17건 포함 전체 단위 테스트 152건(skip 3) 통과, `ruff check .`, `ruff format --check .` 통과.
- **재구현 검증:** 합성 WAMIT 출력(2기, 연성 항 포함)에서 `rao_with_bpto("node")`가 `calculate_rao_matrix`와 `rtol=1e-12`로 일치. 이 폴더에 남아 있던 실제 1기 WAMIT 출력(31개 주파수)에서도 RAO가 3e-16, `B_pto`가 0.0 차이로 일치했습니다.
- **보간 동작:** 합성 공진으로 포물선 꼭짓점이 두 격자 점 사이에 오고, `B_pto`가 이웃 두 점의 `B` 사이에 있으며, 끝점이면 `node`와 같음을 확인. 거친 격자(0.1 간격)에서 보간한 `B_pto`가 촘촘한 격자(0.0125) 값에 더 가깝습니다: 공진 폭이 격자 간격보다 좁으면(폭 약 0.04) 개선이 작고(오차의 0.7~0.8배), 폭이 간격과 비슷하면 크게 줍니다(0.1~0.4배). 즉 보간은 격자가 공진 폭보다 너무 성기면 효과가 제한됩니다. 실제 1기 데이터에서는 보간이 `B_pto`를 -0.28% 바꿨습니다.
- `--dry-run`으로 후보 점 수를 확인(R=2.5, D=5.0: `0.85~1.1` 59점, 미세 0.00625판 84점; R=0.5, D=2.0: 82점, 123점, 확인 격자 801점).

## 5. 남은 이슈 / 후속 작업

- 사용자의 확인 후 `grids --quick`을 제출하고 다음을 확인: (1) `0.85~1.1`이 R=0.5, D=2.0을 통과하는지, (2) 0.003125 격자 대비 0.00625 기준의 수렴, (3) `interp`가 균일 0.05/0.025의 오차를 얼마나 줄이는지와 적응형 격자와의 시간·정확도 비교, (4) `reimpl_check`가 1e-12 이하인지.
- `interp`가 충분히 효과적이면 `src/physics/rao_calc.py`에 적용할지는 별도 승인으로 결정합니다(기존 결과와 비교가 어려워짐).
- 전체 `grids`(형상 9 × 배치 2)와 구현(`FreqGrid`, `FreqAlign`)은 그 뒤에 진행합니다.
