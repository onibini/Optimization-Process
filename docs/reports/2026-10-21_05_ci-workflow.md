# 업데이트 보고서: CI 워크플로를 python-tests.yml로 통합

- 날짜: 2026-10-21
- 범위: `.github/workflows/python-tests.yml`, `CLAUDE.md`, `README.md`, `CHANGELOG.md`, `docs/architecture.md`, `docs/reports/2026-10-21_02_*.md`

## 1. 개요

보고서 02에서 `ci.yml`을 추가하기로 했으나 `.github` 폴더가 보호되어 반영되지 않았고, 저장소에는 기존 `python-tests.yml`(Python 3.10, `test_utils.py`만 실행)만 있었습니다. 새 파일을 만들지 않고 `python-tests.yml`을 확장해 CI를 하나로 통합했습니다.

## 2. 변경 내용

- `lint` 잡: Python 3.12에서 `ruff check .`, `ruff format --check .` 실행 (`requirements-dev.txt`로 ruff 설치).
- `test` 잡: Python 3.8, 3.12 매트릭스에서 `python -m unittest discover -s tests -v` 실행 (기존에는 `tests/test_utils.py`만 실행).
- `actions/checkout`을 v4, `actions/setup-python`을 v5로 올림.
- 문서의 `ci.yml` 표기를 모두 `python-tests.yml`로 변경 (`CLAUDE.md` 구조도, `README.md`, `docs/architecture.md`, `CHANGELOG.md`, 보고서 02).

## 3. 검증

- 로컬(py311)에서 `ruff check .`, `ruff format --check .`, 단위 테스트 55건 통과.
- 워크플로 자체는 GitHub에 푸시해야 실행됩니다. Python 3.8 매트릭스(특히 numpy, scipy, gmsh 설치)는 첫 CI 실행에서 확인이 필요합니다.
