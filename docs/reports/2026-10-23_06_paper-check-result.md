# 업데이트 보고서: 논문 최적해 재현 확인 결과 (paper_check)

- 날짜: 2026-10-23
- 범위: `scripts/experiments/paper_check.py`(진단 확장), `tests/test_paper_check.py`, 분석 결과(코드 `src/` 변경 없음). 결과: `results/20261023_154514_paper_check2/logs/paper_check.csv`(192행), 첫 실행 `20261023_154018_paper_check`

## 1. 개요

논문(동시 최적화 논문 ver14) Table 4의 최적해 6개(부안·칠발도·영일만항 × 순차·동시)를 최적화 없이 현재 평가 과정(균일 0.05 rad/s, 51개)으로 계산해 논문 발전량과 비교했다. 계산용 PC, 메쉬 120과 200.

**현재 기본 설정은 논문을 재현하지 못한다.** 부안·칠발도는 +7~8%, 영일만항은 +32%였다. 원인은 스펙트럼 정의와(영일만항은 추가로) 수심이었다.

## 2. 변경 내용

도구 확장: WAMIT 한 번(`wec.2`·`wec.3` 모두 출력)의 결과를 가진력(diffraction/Haskind) × 스펙트럼(Goda/ITTC) × 적분(Simpson/사다리꼴/직사각형 합)으로 계산하고, 영일만항은 수심 13 m와 이전 값 33 m를 모두 계산한다(`--depths both`). 12조합 × 실행 16회 = 192행.

## 3. 호환성 영향

없음(시험 도구). 단, 아래 결론에 따라 `WaveSpec` 기본값과 `env_data.csv` 수심을 바꿀지는 사용자의 판단이 필요하다(바꾸지 않았다).

## 4. 검증 (결과)

총 발전량의 논문 대비 차이(메쉬 120 / 200, Simpson, diffraction):

| 해역·방식 | 논문 kW | Goda(현재 기본) | ITTC |
| --- | --- | --- | --- |
| 부안 순차 | 47.52 | +7.9% / +8.1% | **-0.8% / -0.6%** |
| 부안 동시 | 50.36 | +8.0% / +8.3% | **-0.7% / -0.4%** |
| 칠발도 순차 | 31.33 | +7.7% / +6.8% | -1.0% / -1.8% |
| 칠발도 동시 | 31.91 | +8.0% / +8.1% | **-0.7% / -0.6%** |
| 영일만항 순차 (수심 13) | 29.23 | +32.1% / +32.5% | +21.4% / +21.8% |
| 영일만항 순차 (수심 33) | 29.23 | +8.2% / +8.5% | **-0.5% / -0.2%** |
| 영일만항 동시 (수심 13) | 29.32 | +32.9% / +33.3% | +22.2% / +22.6% |
| 영일만항 동시 (수심 33) | 29.32 | +7.9% / +8.2% | **-0.8% / -0.5%** |

1. **스펙트럼:** 같은 WAMIT 결과에서 ITTC/Goda 비는 해역과 무관하게 0.919(일정)이다. 두 스펙트럼을 적분해 유의파고를 되짚으면(γ=1.4) ITTC는 입력 Hs의 99.85~100%인 반면 현재 `get_jonswap_spectrum`의 Goda 형식은 Hs를 약 4.1% 크게(부안 1.114 vs 1.07, 칠발도 0.906 vs 0.87, 영일만항 0.958 vs 0.92) 준다 → 전력 +8.4%. 논문 숫자는 ITTC 형식과 일치한다(논문 본문은 Goda라고 쓰지만).
2. **수심:** 영일만항은 수심 13 m(현재 `env_data.csv`, 논문 Table 1)에서는 어떤 조합도 맞지 않고(+19% 이상), **33 m**(2026-10-21 이전 값, 보고서 `2026-10-21_03`에서 13으로 수정)에서 ITTC로 -0.8~+0.1% 일치한다. 즉 논문 영일만항 결과는 수심 33 m로 계산된 것으로 보인다(추정; 논문 Table 1의 13 m와 불일치).
3. **가진력:** Haskind가 diffraction보다 약 0.4% 크다(ITTC 기준 -0.2~-0.7% 대 -0.4~-1.0%로 논문에 약간 더 가깝다). 
4. **적분:** Simpson이 논문에 가장 가깝다(부안은 사다리꼴·직사각형 합이 2~4% 낮음). 직사각형 합과 사다리꼴은 양끝 S≈0이라 같다.
5. **메쉬:** 120 대 200 차이는 0.1~0.9%(칠발도 순차만 1.5%p: x≈15 m 배치가 민감). 논문과의 차이를 설명하지 못한다. 시간은 8 s 대 21 s.
6. 위 일치 후 남은 차이는 -0.2~-1.0%(칠발도 순차 메쉬 200만 -1.8%)이며 논문 당시의 메쉬·가진력 차이 범위로 보인다. 이 잔차의 원인은 확정하지 못했다.

## 5. 남은 이슈 / 후속 작업

**사용자 판단 필요:**
- (a) 논문 계산에 쓴 스펙트럼이 ITTC형이었는지, 코드의 Goda 형식에 정규화 문제(Hs 4.1% 과대)가 있는지. 코드의 Goda는 적분하면 입력 Hs와 맞지 않는다. 논문이 Goda라면 논문 코드와 현재 코드의 식을 대조해야 한다.
- (b) 영일만항 수심: 논문이 실제로 33 m로 계산했다면 논문 Table 1(13 m)과 결과가 불일치한다.
- 어느 쪽이든 현재 기본값(Goda, 13 m)으로 DE를 돌리면 논문 최적해와 비교할 수 없다. 코드(`WaveSpec` 기본값, Goda 식, `env_data.csv`)는 사용자의 결정 전에는 바꾸지 않았다.
- 결정 후: 논문 설정(ITTC, 영일만항 33 m 또는 13 m)으로 DE를 다시 돌려 같은 최적해가 나오는지 확인(별도 확인 필요).
- `FreqGrid`(적응형) 적용은 위 검증이 끝난 뒤에 진행.
