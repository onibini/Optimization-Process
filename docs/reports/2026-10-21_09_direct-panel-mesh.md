# 업데이트 보고서: 패널 수를 직접 지정하는 개선 메쉬

- 날짜: 2026-10-21
- 범위: `src/physics/mesh_axisymmetric_shape.py`(재작성), `src/physics/wamit_handler.py`, `src/problems/*`, `main.py`, `config.cfg`, `requirements.txt`, `tests/test_mesh.py`(신규), `docs/`

## 1. 배경

32-bit WAMIT은 메모리 한계가 있어 형상 변수에 따라 특정 메쉬에서 `Allocation error for complex arrays in ALLARR`가 납니다. 기존 방식의 문제는 다음과 같았습니다.

- `max_elements=300`이 패널 수 상한이 아니었습니다. 실제 전체 패널 수는 형상마다 504~640개(약 1.4~2.1배)였고, 면적 근사와 원주 분할 `//2` 때문에 형상에 따라 ±20% 흔들렸습니다.
- 모든 링에 같은 원주 분할 수를 써서 극점에 길쭉한 패널이 몰렸습니다(면적 최대/최소 4~10, 변 길이 비 최대 약 10).
- 5기 평가 시간이 패널 수의 약 2.5~3제곱으로 늘어 현재 기본값(전체 660 패널)이 이미 평가당 32초였습니다.

## 2. 변경 내용

- `mesh_axisymmetric_shape.py`를 재작성했습니다. 반구는 등각 큐브드스피어 3개 패치(극점 삼각형 팬 없음), 원통은 반구 적도와 같은 각도 분할의 사각형입니다. 1/4 모델(ISX = ISY = 1) 패널 수는 `3n² + 2n·n_z`이고 `choose_grid`가 `target_panels`에 가장 가까운 `(n, n_z)`를 고릅니다(원통 패널의 종횡비에 벌점). gmsh를 거치지 않고 GDF를 직접 씁니다. 사용되지 않게 된 프로파일·회전·gmsh 코드(약 540줄)와 `gmsh` 의존성을 제거했습니다.
- `generate_cylinder_hemisphere_mesh(radius, draft, target_panels=80, output_path=None)`는 실제 1/4 패널 수를 반환합니다. `target_panels < 12`, 비양수 반지름·흘수는 `ValueError`입니다.
- `config.cfg`의 `[WAMIT Settings]`에 `MeshPanels`(기본 80)를 추가했습니다. `main.py`가 읽어 세 문제 모듈의 `config["mesh_panels"]`로 전달하고 `write_wamit_inputs`가 사용합니다. `wec.gdf.meta.json`에 `target_panels`와 메쉬 버전이 들어가므로 같은 형상·패널 수는 재생성하지 않고, 옛 메타(`max_elements`)는 자동으로 재생성됩니다.
- `MeshPanels × 기수`가 1,000을 넘으면 경고합니다(`PANEL_MEMORY_WARN`).

## 3. 검증

기존 방식과 비교한 실측(영일만항 수심 13 m, 수직벽 켬, 이 PC의 32-bit WAMIT)입니다.

- 1기(R=1.5, D=2.5) 파워 오차(무한 패널 외삽 약 332.3 W 기준): 같은 패널 수에서 오차가 약 절반입니다(1/4 패널 약 60: -10% → -4.4%, 약 100: -5% → -2.4%, 약 250: -2.4% → -1.1%). 오차 1%에 필요한 패널은 약 400 → 약 300입니다.
- 5기(R=2.5, D=5.0): 개선 메쉬는 패널 수에 따라 단조 수렴합니다(36: 17,651 W, 69: 17,932 W, 81: 17,940 W, 128: 17,972 W, 205: 17,991 W). 기존 방식은 비단조였습니다(132: 18,119 W, 210: 18,076 W). 5기 총 파워는 둘 다 약 1% 이내입니다.
- 저장소 코드 경로(`MeshPanels=80`)로 실제 WAMIT을 실행: 1기 0.5초 317.80 W, 5기 7.7초 17,939.58 W(시험 코드 결과와 동일). 기존 기본값(5기 전체 660 패널)은 32초였습니다.
- 메모리 한계는 메쉬 종류와 무관하게 전체 패널 약 1,100개였습니다(R=2.5, D=5.0, 5기: 1,075 성공, 1,380 실패. 기존 방식은 1,050 성공, 1,120 실패). 다른 형상·배치에서는 다를 수 있습니다.
- 수선 쪽으로 세로 분할을 촘촘히 하는 변형은 오차가 오히려 약간 커져서 채택하지 않았습니다.
- 테스트 16건 추가(`tests/test_mesh.py`): 패널 수 공식과 목표 일치(±25%), 단조성, 1/4 모델 범위, 꼭짓점이 원통·구면 위에 있음, 법선이 바깥쪽, 젖은 면적이 정확값의 1% 이내, 극점 퇴화 패널 없음과 면적비 4 미만, 입력 오류, `MeshPanels` 전달·캐시·재생성·경고. py311에서 `ruff check .`, `ruff format --check .`, 단위 테스트 75건(skip 3) 통과.
