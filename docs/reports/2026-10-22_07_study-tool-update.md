# 업데이트 보고서: 주파수 격자 시험 도구 개정 (기준 (a), 좁은 구간, 0.00625 기준격자, 덤프)

- 날짜: 2026-10-22
- 범위: `scripts/experiments/freq_grid_study.py`, `src/utils/run_summary.py`, `tests/test_freq_grid_study.py`, `tests/test_run_summary.py`, `docs/frequency_grid_design.md`, `CHANGELOG.md`, `report/`

## 1. 개요

첫 시험(`2026-10-22_06` 보고서)에서 세 판정 기준을 동시에 만족한 격자가 없었고, 현재 균일 0.05 격자의 오차가 크다는 것을 확인했습니다. 승인된 후속 조치로 판정 기준을 (a)로 바꾸고, 시험 도구에 좁은 구간 후보·0.00625 기준격자·주파수별 덤프를 추가하고, `summary.csv`의 `-Script` 작업 행에서 설정 기반 열을 비웠습니다. 계산용 PC에는 제출하지 않았습니다. `src/` 물리 코드와 WAMIT 입력은 바뀌지 않았습니다.

## 2. 변경 내용

- **판정 기준 (a):** 정확도 우선(총 파워 0.1%, 개별 WEC 0.3%, 기준격자 대비). 시간은 "정확도 기준을 만족하는 균일 격자 중 가장 빠른 것"과 비교하며 후보 시간이 그 이하일 때 통과(`TIME_RATIO_MAX = 1.0`, 스크립트 상단 상수). 균일 후보는 0.05, 0.025, 0.0125이고 모두 불합격이면 기준격자의 시간이 기준입니다. 현재 기본 격자(균일 0.05) 대비 시간비도 함께 기록합니다. 정렬(`aligned`) 균일 격자는 기준에서 제외합니다. 순수 함수 `evaluate_verdicts`, `summarize_verdicts`로 구현해 테스트합니다.
- **기준격자:** `ref_uniform_0.00625`(0.5~상한, 401점, 작은 WEC은 585점).
- **후보:** 적응형 `0.7~1.0`, `0.8~1.0`, `0.85~1.0`(모두 미세 0.0125와 꼬리 0.1), `0.8~1.0`+미세 0.00625, 가장 좁은 구간의 NCPU 올림/내림. 첫 시험에서 효과가 없었던 후보(넓은 구간, 미세 0.025, 예산형)는 뺐습니다. 균일 0.025와 0.0125를 새로 넣었습니다(같은 정확도의 균일 격자를 찾기 위해).
- **비제어 피크 진단:** `rao_calc`는 비제어 RAO의 최대점의 방사 감쇠를 `B_pto`로 쓰는데, 이 주파수를 `wec.1`의 `B_kk(ω)`에서 `B_pto`와 일치하는 점으로 복원해 `peak_unctrl_median`, `peak_unctrl_over_w0` 열로 기록합니다(첫 시험의 이상한 결과 원인 분석용).
- **주파수별 덤프:** 사례마다 `logs/dump_<R>_<D>_<배치>_<격자>.csv`에 `omega`, `S`, 5기의 `B_k`, `rao_k`, `bpto_k`, `density_k`(`b·ω²·rao²·S`)를 저장합니다. `--no-dump`로 끕니다.
- **출력:** `freq_grid_study_grids.csv`(사례별), `freq_grid_study_grids_verdict.csv`(판정), 실행 끝의 후보별 요약 표.
- **`summary.csv`:** `-Script` 작업은 `config.cfg` 기반 열(`site_id`, `opt_mode`, `algorithm`, `num_wecs`, `pop_size`, `max_iter`, `mesh_panels`, `solver`, `omega_max`)과 결과 열을 비웁니다.

## 3. 호환성 영향

- `src/`, `config.cfg`, `main.py`, WAMIT 입력은 그대로입니다. 시험 도구의 후보 이름과 출력 열이 바뀌어 이전 시험의 CSV와 열이 다릅니다(`peak_unctrl_*` 추가).
- `summary.csv`의 `-Script` 작업 행(`20261022_161733_fgrid_quick` 포함)이 다음 `fetch`/`summarize_results.py`에서 설정 열이 빈 값으로 다시 만들어집니다.
- `grids --quick`의 계산 시간이 늘어납니다: 기준격자(401~585점)와 균일 0.025/0.0125 후보가 추가되어 약 15분으로 예상합니다(첫 시험 8.5분, 점 수 합계 약 4,000에서 약 5,000, 점당 약 0.13초 기준).

## 4. 검증

- 이 PC에서 WAMIT 없이 확인: `--dry-run`으로 입력 생성과 후보 점 수(R=2.5, D=5.0: 균일 51, 적응형 0.85~1.0 51점, 0.8~1.0 54점, 0.7~1.0 61점, 정렬 올림 56/내림 48), 새 함수 테스트(판정 기준과 경계값 0.1/0.3, 균일 정렬 격자 제외, 기준격자가 유일한 균일 합격일 때, 사례별 판정과 요약, `wec.1`의 감쇠 스케일링과 DOF 선택, 비제어 피크 복원, 덤프 형식, 후보 목록과 점 수, 측정된 공진이 좁은 구간의 0.0125 간격 안에 있는지).
- 실제 파일에서 확인: 이 폴더에 남아 있던 이전 WAMIT 출력(1기, 31개 주파수)에 `calculate_rao_matrix`를 적용해 `B_pto`와 `B_kk(ω)`가 정확히 일치하는 주파수(1.35)를 복원했고(상대 불일치 0) 덤프를 써 보았습니다.
- `ruff check .`, `ruff format --check .`, 단위 테스트 135건(skip 3) 통과.

## 5. 남은 이슈 / 후속 작업

- 사용자의 확인 후 `grids --quick`을 계산용 PC에 제출하고, 판정 요약과 덤프로 (1) 어느 구간(0.7, 0.8, 0.85)이 기준 (a)를 통과하는지, (2) 0.00625 기준격자가 0.0125 균일 격자와 얼마나 다른지(기준의 수렴), (3) `wide` 구간이 나빴던 원인을 확인.
- 작은/가는 형상에서 0.0125로 부족하면 0.00625 미세 후보 결과로 판단.
- 통과한 격자가 정해진 뒤 `FreqGrid`/`FreqAlign` 구현(설계 5절).
