# 논문 최적해를 다시 계산해 보는 도구

- 날짜: 2026-10-23
- 아직 계산용 컴퓨터에 보내지 않았어요. 도구만 만들고 테스트했어요.

## 1. 왜 필요한가요?

눈금(주파수)을 바꾸기 전에, **지금 프로그램이 논문에 쓴 결과를 그대로 낼 수 있는지** 먼저 확인해야 해요. 시험지 정답이 있는데, 내 계산기가 그 정답을 내는지 보는 거예요.

## 2. 무엇을 하나요?

- 논문 표(Table 4)에 있는 **부안, 칠발도, 영일만항**의 최적 설계 6개(순차 3개, 동시 3개)를 가져와요.
- 최적화는 하지 않고, 그 설계로 **발전량만 한 번씩 계산**해요.
- 논문의 발전량(예: 부안 동시 50.36 kW)과 얼마나 다른지 표로 만들어요.

## 3. 조심한 점

논문은 "가운데 부표"를 3번이라고 부르고, 이 프로그램은 1번이라고 불러요. 이름이 달라서 숫자를 그대로 넣으면 **배치가 달라져요**. 그래서 순서를 바꿔 넣었고, 5개 부표의 위치가 논문과 똑같은지 테스트로 확인했어요.

## 4. 여러 가지로 계산해 봐요

같은 설계를 4가지 방법으로 계산해서, 차이가 **계산 방법 때문인지** 알아봐요.

| 이름 | 뜻 |
| --- | --- |
| base | 지금 기본 설정 |
| fg | 공진 부근을 촘촘하게 (FreqGrid=1) |
| mesh200 | 표면을 더 잘게 (200조각) |
| mesh200fg | 둘 다 |

## 5. 다음에 할 일

1. 허락해 주시면 계산용 컴퓨터에서 돌려요(24번 계산).
2. 논문과 다르면 이유를 찾아요. 예전에 고친 버그(보고서 01~04) 때문인지, 눈금·표면 때문인지 가려내요.
3. 그다음에 논문과 같은 조건으로 최적화를 다시 돌려 같은 설계가 나오는지 봐요.
