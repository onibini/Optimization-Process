# WAMIT 여러 개 동시에 돌리기

- 날짜: 2026-10-23

## 1. 무엇이 바뀌었나요?

이제 WAMIT을 **여러 개 동시에** 돌릴 수 있어요. `config.cfg`의 `Workers`를 2나 4로 하면 돼요.

비유하면, 지금까지는 계산원 한 명이 손님 100명을 차례로 계산했어요. 이제는 계산대를 여러 개 열어서 손님을 나눠 받아요. 계산원마다 **자기 책상(작업 폴더)**이 있어서 서로 섞이지 않아요.

## 2. 어디에 쓰이나요?

| 방법 | 동시에 돌릴 수 있나요? |
| --- | --- |
| 처음 후보들 계산 | 모든 방법에서 돼요 |
| GA, CMA-ES | 매 세대 전부 돼요 |
| DE | `DEUpdate=1`로 하면 돼요(논문과는 방식이 조금 달라져요) |
| PSO, DEPSO | 처음 후보만 돼요 |

## 3. 결과가 바뀌나요?

**아니요.** 한 명씩 계산한 것과 결과가 똑같은 것을 테스트로 확인했어요. 빨라지기만 해요.

## 4. 아직 안 한 것

진짜로 얼마나 빨라지는지는 계산용 컴퓨터에서 재야 해요. 지금은 CMA-ES 계산 중이라, 끝나면 재 볼 거예요. 재는 도구는 미리 만들어 뒀어요.
