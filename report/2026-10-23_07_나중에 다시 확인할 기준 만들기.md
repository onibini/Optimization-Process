# 나중에 다시 확인할 기준 만들기

- 날짜: 2026-10-23

## 1. 무엇을 했나요?

프로그램의 어떤 파일을 고친 뒤에 "결과가 달라졌나?" 하고 확인하려면 **비교할 기준**이 있어야 해요. 그래서 오늘 계산한 결과를 정리해서 `docs/validation` 폴더에 저장했어요.

## 2. 기준에 들어 있는 것

- 논문의 최적 설계 6개를 지금 프로그램으로 계산한 **발전량 192개 값**.
- 부안과 칠발도는 논문과 **1% 안쪽**으로 잘 맞았어요. 그러니 지금 계산 방법의 정확도는 나쁘지 않아요.
- 영일만항은 환경 파일의 깊이(33 m)가 잘못 적혀 있어서 논문 값과 다르게 나왔어요. 진짜 깊이는 13 m예요.
- 파도 공식(Goda)이 에너지를 8% 크게 계산한다는 것도 적어 두었어요.

## 3. 어떻게 쓰나요?

파일을 고친 뒤에 계산용 컴퓨터에서 같은 계산을 다시 하고 `--reference` 옵션을 켜면, 저장해 둔 값과 **0.2% 넘게 달라진 곳**을 알려줘요. 예를 들어 코드를 정리만 했는데 값이 달라졌다면 뭔가 잘못된 거예요.

| 고친 것 | 이렇게 되어야 해요 |
| --- | --- |
| 코드 정리 | 모든 값이 똑같아요 |
| 파도 공식 고침 | Goda 값만 달라져요 |
| 깊이 파일 고침 | 그 바다 값만 달라져요 |

## 4. 아직 안 풀린 문제

- 논문이 어떤 파도 공식을 썼는지 아직 확인이 필요해요.
- 맞춘 뒤에도 0.2~1.8% 정도 남는 차이는 이유를 몰라요.
