# CMA-ES 다시 보내기

- 날짜: 2026-10-23

## 1. 무엇을 했나요?

CMA-ES의 걸음 크기 문제를 고친 뒤, 계산용 컴퓨터에서 돌던 계산(고치기 전 코드)을 멈추고 **고친 코드로 다시 보냈어요.** 2.5시간쯤 계산한 것은 버렸어요. 대신 결과를 믿을 수 있어요.

## 2. 보내기 전에 하나 더 시험했어요

부표 문제의 변수는 눈금 크기가 달라요. 반지름은 20칸, 위치는 300칸쯤이에요. 그래서 끝 무렵에 반지름처럼 눈금이 큰 변수는 "한 칸도 못 움직이는" 일이 생길 수 있어요. 그래서 **변수마다 최소한 이만큼은 흔들어 보기** 기능을 만들어 시험했어요.

![비교](images/2026-10-23_13_cmaes_minstd_final_D7.png)

| 흔드는 정도 | 결과 |
| --- | --- |
| 안 함 | 가장 좋음 |
| 조금(0.3, 0.5) | 거의 같음 |
| 많이(1.0) | 오히려 나빠짐 |

도움이 안 돼서 **끈 채로** 보냈어요.

## 3. 다시 보낸 계산

- 한 번에 72개씩 300번, 파도 공식 ITTC, 부안 → 칠발도 → 영일만항 순서
- 예상 시간: 약 4~5일

## 4. 덤으로 알게 된 것

진짜 부표 문제처럼 눈금 크기가 다른 연습 문제에서는 **CMA-ES가 DE보다 좋았어요.** 진짜 결과가 어떻게 나올지 기대돼요.
