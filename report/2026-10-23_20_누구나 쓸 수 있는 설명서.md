# 누구나 쓸 수 있는 설명서

- 날짜: 2026-10-23

## 1. 무엇을 고쳤나요?

이 프로그램은 **다른 사람들도 쓸 수 있게** 공개하는 거예요. 그런데 앞에서 쓴 설명서에는 **만든 사람에게만 해당하는 내용**이 섞여 있었어요.

| 뺀 것 | 이유 |
| --- | --- |
| 계산용 컴퓨터로 보내는 방법을 기본처럼 설명 | 다른 사람은 그런 컴퓨터가 없을 수 있어요 |
| 논문과 프로그램의 부표 번호가 다르다는 안내 | 만든 사람의 논문과 비교할 때만 필요해요 |
| 논문 값과 맞추는 설정 | 다른 사람에게는 필요 없어요 |

## 2. 새로 넣은 것

- 프로그램이 **어떤 순서로 계산하는지** 쉬운 설명
- 부표 번호와 위치를 정하는 **프로그램의 규칙**
- 처음 쓸 때 **작게 돌려 시간을 재 보는 법**
- 새 바다(해역)를 **추가하는 법**
- 다른 모양이나 개수를 쓰고 싶을 때 **어디를 고치면 되는지**

계산용 컴퓨터로 보내는 기능은 "필요한 사람만 쓰는 부가 도구"로 짧게만 남겼어요.
