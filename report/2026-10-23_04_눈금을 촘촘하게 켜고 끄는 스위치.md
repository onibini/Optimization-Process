# 눈금을 촘촘하게 켜고 끄는 스위치 (FreqGrid)

- 날짜: 2026-10-23

## 1. 무엇이 바뀌었나요?

`config.cfg`에 스위치를 하나 달았어요. 이름은 **FreqGrid**예요.

| 값 | 뜻 |
| --- | --- |
| 0 (지금 기본) | 예전처럼 0.5부터 0.05씩 똑같은 간격으로 재요 |
| 1 | 부표가 **크게 흔들리는 곳(공진)** 근처만 아주 촘촘하게(0.00625), 아주 높은 곳은 듬성듬성 재요 |

## 2. 왜 필요했나요?

공진 근처는 산처럼 뾰족해서, 간격이 넓으면 산꼭대기를 놓쳐요. 시험에서 지금 방법은 전기량을 **1~11%** 틀리게 계산했고, 어떤 부표 하나는 **42%**까지 틀렸어요. 스위치를 1로 하면 오차가 **0.1% 안쪽**으로 줄어요(가장 가는 부표는 0.3% 안쪽).

## 3. 대가는?

점이 늘어서 계산 시간이 **1.5 ~ 2.5배** 걸려요. 그래도 모든 곳을 촘촘하게 재는 것보다는 훨씬 빨라요.

## 4. 어떻게 확인했나요?

- 스위치를 0으로 두면 WAMIT에 보내는 파일이 **예전과 똑같은지** 테스트했어요.
- 1로 하면 시험에서 쓴 눈금과 **똑같이** 만들어지는지 6가지 부표로 확인했어요.
- 자동 테스트 166개가 모두 통과했어요.
- 진짜 WAMIT는 이번에 돌리지 않았어요.

## 5. 아직 안 풀린 문제

- 아주 가늘고 긴 부표는 아슬아슬해요(0.26%). 더 가는 부표를 쓰려면 "두 번 재기"가 필요할 수 있어요.
- 작고 얕은 부표는 공진이 재는 범위 밖에 있어서 이 스위치가 효과가 없어요.
- 진짜 최적화에서 시간이 얼마나 더 걸리는지는 계산용 컴퓨터에서 확인해야 해요.
