# 계산용 컴퓨터에 시험 도구 보내기 (보내는 길을 열어 두었어요)

- 날짜: 2026-10-22
- 이번에 한 일: 계산용 컴퓨터로 **"시험 프로그램"도 보낼 수 있게** 보내는 길을 넓혔어요. 그리고 지난번에 만든 설계안에서 **무엇을 하기로 했는지** 정리했어요.
- **계산용 컴퓨터에는 아직 아무것도 보내지 않았어요.** 확인해 주시면 그때 보낼 거예요.

---

## 1. 무슨 문제가 있었나요?

계산용 컴퓨터에 일을 맡기는 명령(`remote.ps1 submit`)은 **언제나 똑같은 프로그램(`main.py`)만** 돌렸어요. 그런데 이번에는 "눈금을 바꿔 가며 어느 쪽이 더 정확한지" 알아보는 **시험 프로그램**을 돌리고 싶었어요. 식당에 비유하면 이래요.

> 지금까지는 주방(계산용 컴퓨터)에 "오늘의 메뉴"만 주문할 수 있었어요. 이번에는 "새 레시피를 시험해 보세요"라고 **다른 요리**도 부탁하고 싶은 거예요.

## 2. 어떻게 바꿨나요?

주문서에 **"어떤 프로그램을 돌릴지"** 쓰는 칸(`-Script`)을 만들었어요.

```
.\scripts\remote.ps1 submit -Script scripts/experiments/freq_grid_study.py -ScriptArgs "--study grids --quick" -Wait
```

- **쪽지로 전하기:** 프로그램 이름과 "빠르게 해 보세요" 같은 주문 내용을 전화(SSH)로 말하면 따옴표 같은 기호가 **뭉개져서** 전해져요. 그래서 **쪽지(`_job.json`)에 적어서 짐 상자 안에 넣어** 보내요. 상자를 열면 주방에서 쪽지를 읽고 그대로 요리해요.
- **안전하게:** 프로젝트 밖에 있는 파일이거나, 보내지지 않는 폴더(`docs`, `tests` 등)에 있거나, 파이썬 파일이 아니면 **보내기 전에 막아요.**
- **연습 모드(`-DryRun`):** 짐 상자만 싸 보고 안에 뭐가 들었는지 보여 주는 연습 모드예요. 계산용 컴퓨터에 **전화를 걸지 않아요.**
- **결과표에도 표시:** 결과를 정리한 표(`summary.csv`)에 "어떤 프로그램을 돌렸는지" 칸이 생겼어요.

## 3. 잘 되는지 확인했나요?

이 컴퓨터에서 **전화를 걸지 않고** 확인했어요.

| 확인한 것 | 결과 |
| --- | --- |
| 연습 모드로 짐 싸기 (시험 프로그램) | 파일 57개, 쪽지 들어 있음 |
| 연습 모드로 짐 싸기 (평소 프로그램) | 파일 56개, 쪽지 없음 (평소처럼 `main.py`) |
| 없는 파일, `tests` 폴더 파일, 파이썬이 아닌 파일, 프로젝트 밖 파일 | 모두 "안 돼요" 하고 멈춤 |
| 주방 역할 프로그램에 쪽지 있는 가짜 일 시키기 | 쪽지대로 돌고 결과를 상자에 담음 |
| 쪽지 없는 가짜 일 시키기 | 평소처럼 `main.py`를 돌림 |

아직 **진짜 전화(SSH)로 보내 보지는 않았어요.** 그 부분은 처음 보낼 때 확인돼요.

## 4. 지난 설계안에서 정한 것

지난번 글(눈금을 똑똑하게 정하기)에서 질문했던 것들을 이렇게 정했어요.

1. 새 눈금은 **처음에는 꺼 둬요.** 시험이 끝나고 괜찮으면 새 계산에 켜요.
2. 작은 부표의 눈금 끝을 **자동으로 늘리는 것은 "고를 수 있는 옵션"**으로 해요. (처음부터 켜지 않아요.)
3. "합격" 기준: 전체 전기량은 **0.1% 이내**, 부표 하나하나는 **0.3% 이내**, 시간은 지금보다 **10% 넘게 늘지 않기**.
4. 계산용 컴퓨터로 시험 프로그램을 보내는 길을 여는 것을 허락했어요. (이번에 했어요.)

## 5. 다음에 할 일

1. 보내는 길과 시험 도구를 **한 번 확인**해 주세요.
2. 확인해 주시면 계산용 컴퓨터에 **빠른 시험**(약 10분)을 보내요.
3. 결과를 보고 새 눈금의 구간과 합격 기준이 맞는지 확인한 뒤, 진짜로 프로그램에 넣어요.
