# 세 번째 눈금 시험 결과: 윗쪽 끝을 늘리니 좋아졌어요, 곡선으로 꼭대기 찾기는 큰 도움이 안 됐어요

- 날짜: 2026-10-23
- 계산용 컴퓨터에서 **약 15분** 걸려 시험을 마쳤어요.
- 자세한 숫자는 `docs/reports/2026-10-23_01_freq-grid-quick3-study.md`에 있어요.

---

## 1. 윗쪽 끝을 1.1배로 늘렸더니 (좋아졌어요)

촘촘하게 하는 구간의 **윗쪽 끝**을 예측 공진 빠르기의 1.0배에서 **1.1배**로 늘렸어요. 공진의 오른쪽 자락까지 담긴 덕분에, 오차가 줄었어요.

| 부표 모양 | 부표 하나만 봤을 때 가장 많이 틀린 정도: 1.0배 → 1.1배 |
| --- | --- |
| 중간 (1.5, 2.5) | 0.11% → **0.06%** |
| 작고 얕음 (0.5, 0.5) | 0.04% → **0.02%** |
| 크고 깊음 (2.5, 5.0) | 0.23% → 0.22% (거의 같아요) |

점은 조금 더 필요해요(예: 51개 → 59개). 시간은 지금 쓰는 눈금보다 **1.1~1.65배** 걸리지만, 같은 정확도를 내는 보통 눈금(점 201개)보다는 **2~4배 빨라요.**

## 2. 곡선으로 꼭대기 찾기 (기대만큼은 아니에요)

점들 사이를 곡선으로 이어서 "진짜 꼭대기"를 찾는 방법을 함께 시험했어요. 결과는 이랬어요.

- 눈금이 **성길 때**(지금 쓰는 0.05 간격): 전체 전기량의 오차가 조금 줄기도 하고(-1.2% → +0.2%) 늘기도 했어요(+11.5% → +12.0%). 부표 하나하나를 보면 거의 **그대로**였어요(예: 14.9% → 13.8%).
- 눈금이 **촘촘할 때**: 곡선이 오히려 조금 **더 틀리게** 만든 경우도 있었어요.

> 왜일까요? 틀리는 이유의 대부분이 "꼭대기를 어디로 고르느냐"가 아니에요. **아주 좁은 산(공진)을 점 몇 개로 재서** 면적(전기량)을 구하기 때문이에요. 산이 좁으면 점이 더 많이 필요해요.

그래서 **곡선 방법은 계산 프로그램에 넣지 않는 편**이 좋겠다고 판단해요.

## 3. 안 풀린 모양은 이유를 알았어요 (가늘고 긴 부표)

이 모양은 산의 폭이 **아주 좁아요**(약 0.03~0.04). 이번에 더 촘촘한 정답용 눈금(0.003125 간격)으로 확인해 보니:

| 눈금 간격 | 전체 전기량 오차 |
| --- | --- |
| 0.003125 (가장 촘촘한 기준) | 0 |
| 0.00625 (지금까지의 정답) | +0.07% |
| 0.0125 | +0.31% |
| 0.025 | -2.4% |

- 간격을 반으로 줄일 때마다 오차가 약 **5분의 1**로 줄어요.
- **지금까지 정답으로 삼은 눈금(0.00625)도 부표 하나하나로는 0.28%까지 틀려 있었어요.** 합격 기준(0.3%)에 거의 닿아요. 그래서 이 모양에서는 더 촘촘한 눈금을 정답으로 삼아야 해요.
- 새 정답(0.003125)으로 다시 재면 **촘촘한 구간을 0.00625 간격으로 한 눈금은 합격 범위**(전체 0.06%, 부표 하나 0.26%)에 들어와요. 0.0125 간격은 여전히 불합격(0.4%)이에요.

**정리:** 산이 좁을수록 간격이 더 촘촘해야 하고, 그 폭은 부표마다 달라요.

## 4. 지금까지 정리

| 선택지 | 정확도 | 시간 (지금 눈금의 몇 배) |
| --- | --- | --- |
| 지금 쓰는 눈금 | 많이 틀려요 (최대 11% / 42%) | 1배 |
| 촘촘한 구간 0.85~1.1배, 0.0125 간격 | 대부분 합격 (부표 하나 0.22% 이내) | 1.1~1.65배 |
| 같은 구간, 0.00625 간격 | 아주 좋아요 (0.02% 이내) | 1.5~2.5배 |
| 같은 정확도의 보통 눈금 (점 201개 이상) | 합격 | 3.4~6.7배 |

## 5. 다음에 정할 것

1. **자동으로 간격 고르기:** 먼저 성긴 눈금으로 한 번 재서 **산의 폭**을 알아내고, 그 폭에 맞춰 촘촘한 간격을 정하는 방법(2단계)을 시험해 볼까요? 부표마다 산의 폭이 다른 문제를 풀 수 있어요. 대신 계산을 두 번 해요.
2. 아니면 **0.85~1.1배 + 0.0125 간격**을 기본으로 하고, 아주 좁은 모양은 따로 간격을 고르게 할까요?
3. 합격 기준을 정할 때 **정답 눈금 자체의 오차**(좁은 산에서 0.07%/0.28%)를 반영할까요?
