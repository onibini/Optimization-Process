# 산의 폭에 맞춰 두 번 재는 눈금 (아직 계산용 컴퓨터에 안 보냈어요)

- 날짜: 2026-10-23
- 지난번 시험에서 "산(공진)이 좁을수록 눈금을 더 촘촘하게 해야 하고, 그 폭은 부표마다 달라서 미리 알기 어렵다"는 것을 알았어요. 그래서 **먼저 대충 재 보고, 산의 폭을 알아낸 다음 필요한 곳만 다시 촘촘하게 재는** 방법을 시험 도구에 넣었어요.
- **계산용 컴퓨터에는 보내지 않았어요.** 이 컴퓨터에서 가짜 계산기로 전체 시험을 돌려 보고 테스트만 했어요.
- 곡선으로 꼭대기 찾기는 효과가 없어서 **시험 도구에서 뺐어요.** 계산 프로그램(`src`)은 하나도 고치지 않았어요.

---

## 1. 어떻게 재나요? (두 번 재기)

산 모양 언덕의 높이를 점으로 재서 면적을 구한다고 해요. 언덕이 **좁고 높으면** 점을 아주 촘촘히 찍어야 해요. 그런데 언덕이 어디에 있고 얼마나 좁은지 모르면 어떻게 할까요? 이렇게 해요.

1. **1차 (대충 재기):** 지금 쓰는 눈금(0.05 간격, 51개)으로 한 번 재요. 이건 어차피 하던 일이라 따로 시간이 들지 않아요.
2. **산 찾기:** 1차 결과로 부표마다 **가장 크게 흔들리는 자리**와 **산의 폭**을 어림해요. 폭은 간단한 식으로 구해요: *폭 ≈ 2 × (물이 부표를 말리는 힘) ÷ (부표 무게 + 물의 무게 효과)*. (그네를 밀 때, 마찰이 클수록 폭이 넓은 것과 같아요.)
3. **2차 (필요한 곳만 촘촘하게):** 산의 **양쪽으로 폭의 4배**만큼 범위를 잡고, 그 안을 *폭 ÷ 6* 또는 *폭 ÷ 10* 간격으로 촘촘히 재요. 좁은 산은 아주 촘촘하게(0.003125), 넓은 산은 덜 촘촘하게(0.0125) 해요.
4. **합치기:** 1차와 2차 결과를 합쳐서 전기량을 계산해요. 시간도 1차 + 2차를 **더해서** 비교해요.

> 이렇게 하면 **부표마다 다른 산의 폭**에 눈금이 저절로 맞춰져요. 대신 계산을 두 번 해야 해서 고정 시간(약 1초)이 더 들어요.

## 2. 얼마나 촘촘해질까요? (예시)

2차에서 새로 재는 점의 개수 예시예요(1차 51개에 더해져요).

| 산의 폭 | 2차 간격 (폭÷6 / 폭÷10) | 새로 재는 점 (폭÷6 / 폭÷10) |
| --- | --- | --- |
| 아주 좁음 (0.03) | 0.003125 / 0.003125 | 72 / 72 |
| 좁음 (0.06) | 0.00625 / 0.003125 | 68 / 144 |
| 넓음 (0.12) | 0.0125 / 0.00625 | 58 / 134 |
| 아주 넓음 (0.3) | 0.0125 / 0.0125 | 114 / 114 |

## 3. 폭 어림이 얼마나 맞을까요?

지난번 시험 결과에서 **어림한 폭 ÷ 실제 폭**을 확인했어요. 부표 5개 중 **가장 좁은 산**(간격을 정하는 값)의 비율이에요.

| 부표 모양 | 어림 ÷ 실제 |
| --- | --- |
| 크고 깊음 | 0.7 |
| 중간 | 0.78 |
| 작고 얕음 | **2.4** (실제보다 넓게 어림했어요) |
| 가늘고 긴 | 0.93 |

대부분 실제보다 **좁게** 어림해서 안전한 쪽(더 촘촘하게)이에요. 작고 얕은 부표만 실제보다 **넓게** 어림해서 덜 촘촘해질 수 있는데, 이 모양은 간격 0.0125면 충분하다는 것이 이미 확인되어 있어요. 이번 시험에서 확인할 거예요.

## 4. 어떻게 확인했나요?

- **가짜 계산기로 전체를 돌려 봤어요.** 진짜 WAMIT 대신 쉬운 식으로 만든 가짜 결과를 써서, 시험 도구가 처음부터 끝까지(두 번 재기, 합치기, 표 만들기, 청소) 잘 돌아가는지 확인했어요. 시험 표가 57줄 나왔고 합산이 맞았어요.
- 1차와 2차 결과를 **합친 것**이 **한 번에 잰 것**과 같은 답을 주는지 확인했어요(거의 완전히 같았어요).
- 폭을 어림하는 계산이 식과 맞는지, 간격과 범위가 제대로 정해지는지 자동 테스트로 확인했어요.
- 자동 테스트 **152개**가 모두 통과했어요.

## 5. 다음에 할 일

1. 확인해 주시면 **빠른 시험**을 계산용 컴퓨터에 보내요. 예상 시간은 **약 17~18분**이에요.
2. 결과로 알아볼 것:
   - 두 번 재기가 **가늘고 긴 부표**도 합격하게 만드나요?
   - **시간(1차+2차)**은 지금의 "촘촘한 구간" 방법(0.85~1.1배)이나 보통 눈금보다 얼마나 걸리나요?
   - 폭 어림이 실제와 맞나요?
3. 결과를 보고 **어느 방법을 진짜 프로그램에 넣을지** 정해요. 두 번 재기는 정확하지만 구조가 조금 더 복잡해요.
