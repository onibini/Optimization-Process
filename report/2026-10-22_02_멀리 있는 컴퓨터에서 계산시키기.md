# 멀리 있는 컴퓨터에 계산 심부름 시키기

## 무엇이 바뀌었나요?
전에는 이렇게 했어요.
1. 이 컴퓨터에서 코드를 고쳐요.
2. 폴더 전체를 USB나 클라우드로 **통째로 복사**해요.
3. 계산용 컴퓨터에서 직접 실행해요.
4. 끝나면 결과를 **다시 복사**해서 가져와요.

이제는 명령 한 줄이면 돼요.
```
.\scripts\remote.ps1 submit -Name site3 -Wait
```
나머지는 컴퓨터가 알아서 해요.

## 비유로 이해하기
- 이 컴퓨터는 **주방장의 레시피 노트**예요.
- 계산용 컴퓨터는 **큰 주방**이에요.
- 예전에는 노트를 통째로 들고 큰 주방에 가서 요리하고, 음식을 다시 들고 왔어요.
- 이제는 **전화로 주문**해요. 큰 주방이 요리하고, 다 되면 음식(결과)이 **배달**돼요.

## 어떻게 연결하나요?
두 컴퓨터가 다른 건물(다른 인터넷)에 있어서 먼저 **비밀 터널**이 필요해요.

| 이름 | 하는 일 | 비유 |
| --- | --- | --- |
| Tailscale | 멀리 있는 두 컴퓨터를 같은 방에 있는 것처럼 이어 줘요 | 비밀 터널 |
| SSH | 터널 안에서 안전하게 명령을 보내요 | 잠금장치 달린 전화 |
| 열쇠(SSH 키) | 비밀번호 없이 "나 맞아요"를 증명해요 | 우리 집 열쇠 |

## 명령을 내리면 일어나는 일
1. 코드와 설정을 **작은 가방**에 싸서 보내요. (계산 결과 같은 큰 짐은 빼요.)
2. 계산용 컴퓨터에 **새 폴더**를 만들고 거기서 계산해요. 계산이 여러 개여도 서로 안 섞여요.
3. 연결이 끊겨도, 이 컴퓨터를 꺼도 계산은 **계속돼요**.
4. 끝나면 결과가 `results\날짜_이름\` 폴더로 **자동으로** 들어와요.
5. `results\summary.csv`라는 **성적표**에 한 줄이 더해져요. 설정, 최고 파워, 걸린 시간이 적혀 있어서 여러 번 돌린 결과를 한눈에 비교할 수 있어요.

## 쓸 수 있는 명령
| 명령 | 뜻 |
| --- | --- |
| `submit` | 계산 보내기 (`-Wait`를 붙이면 끝까지 기다렸다가 결과도 가져와요) |
| `status` | 지금 어떤 상태인지 보기 |
| `tail` | 계산 화면의 마지막 부분 보기 |
| `fetch` | 결과 가져오기 |
| `stop` | 계산 멈추기 |
| `list` | 계산용 컴퓨터의 작업 목록 보기 |

## 확인한 것과 아직 못 한 것
- **확인함**: 실제로 두 컴퓨터 사이에서 짧은 계산(반복 2번)을 보냈고, 약 6초 만에 끝나서 결과와 성적표(`summary.csv`)가 자동으로 들어왔어요. 보내기, 계산, 가져오기가 모두 한 번에 됐어요.
- **중간에 막혔던 것들** (숨기지 않고 적어요):
  - 컴퓨터가 "스크립트 실행은 안 돼요"라고 막았어요. 내 계정에만 허용해서 풀었어요.
  - 계산용 컴퓨터에서 `python`이라고 불러도 대답하지 않았어요. conda 안에 있는 Python의 **정확한 주소**를 적어 줘서 해결했어요.
  - 명령에 띄어쓰기가 있으면 따옴표가 사라져서 오류가 났어요. 제가 처음에 그런 명령을 알려 준 것이 잘못이었어요.
  - 명령을 엉뚱한 폴더에서 실행하거나, 아직 만들지 않은 파일을 쓰려다 막힌 적도 있어요.
- **아직 못 함**: 몇 시간씩 걸리는 **긴 계산**은 아직 안 해 봤어요. 중간에 연결이 끊겼다가 다시 이어지는 경우도 시험 전이에요.
- 계산용 컴퓨터가 **잠들면** 계산도 멈춰요. 절전 기능을 꺼 두세요.
