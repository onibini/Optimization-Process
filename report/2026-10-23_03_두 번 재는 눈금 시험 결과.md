# 두 번 재는 눈금 시험 결과

- 날짜: 2026-10-23
- 계산용 컴퓨터에서 약 17분 동안 시험을 돌렸어요. 코드는 하나도 바꾸지 않았고, 결과를 읽고 정리만 했어요.

---

## 1. 무엇을 시험했나요?

"먼저 대충 재고, 산(공진)의 위치와 폭을 알아낸 다음, 필요한 곳만 촘촘히 다시 재는" 두 번 재기 방법이 정말 잘 맞는지 부표 모양 4가지로 시험했어요. 정답은 아주 촘촘히 잰 값이에요.

## 2. 결과

| 방법 | 합격한 모양 (4개 중) |
| --- | --- |
| 지금 쓰는 눈금 (0.05) | **0개** (오차가 1~11%, 어떤 부표는 42%나 틀려요) |
| 보통 눈금을 촘촘하게 (0.0125) | 3개 |
| 산 근처만 촘촘하게 | 3개 |
| **두 번 재기 (폭÷6)** | **4개 전부** |
| 두 번 재기 (폭÷10) | 3개 (한 모양에서 너무 오래 걸렸어요) |

- 두 번 재기는 오차가 **0.01% ~ 0.3% 안쪽**이었어요. 지금 방법보다 수백 배 정확해요.
- 시간은 지금 방법의 **2.3 ~ 2.8배** 걸려요. 하지만 보통 눈금을 촘촘하게 하는 것보다는 **20% ~ 60% 빨라요**.
- 산의 폭을 어림한 값은 대부분 실제보다 조금 좁게 나왔어요(안전한 쪽). 한 모양(작고 얕은 부표)만 2배 넓게 어림했지만, 그래도 결과는 정확했어요.

## 3. 가늘고 긴 부표는?

가장 어려운 모양이에요. 산이 아주 좁아서 지금까지는 어떤 방법도 합격하지 못했어요. 두 번 재기는 **오차 0.01%**로 합격했어요(가장 촘촘한 값과 거의 같았어요).

## 4. 솔직하게 말할 점

처음에 "두 번 재기만 합격했다"고 생각했는데, 자세히 보니 **"산 근처만 촘촘하게" 방법도 가장 촘촘한 값과 비교하면 합격할 정도**였어요. 합격표에서 떨어진 것은 정답으로 쓴 값(0.00625 간격)이 조금 틀렸기 때문이었어요. 그러니까:

- 두 번 재기의 좋은 점: 부표 모양을 몰라도 **산 폭에 맞게 알아서 간격을 조절**해요. 더 가는 부표가 나와도 안전해요.
- 아쉬운 점: "산 근처만 촘촘하게"보다 **조금 더 오래 걸리고**, 프로그램이 더 복잡해져요(WAMIT을 두 번 돌려야 해요).

## 5. 다음에 할 일

어느 방법을 진짜 프로그램에 넣을지 정해야 해요.

- **간단한 방법**(산 근처만 촘촘하게): 빠르고 단순해요. 부표가 너무 가늘지 않으면 충분해요.
- **두 번 재기**: 조금 느리지만 어떤 모양에도 안전해요.

설계할 부표의 반지름과 길이 범위를 알면 고르기가 쉬워요.
